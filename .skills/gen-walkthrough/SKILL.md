# Skill: /gen-walkthrough
## Objetivo
Gerar o artefato de documentação técnica e o registro dos commits atômicos executados durante a tarefa.

## Instruções de Execução
1. Analisar o diff das alterações realizadas no repositório.
2. Verificar se os commits seguiram o padrão Conventional Commits vinculados às tasks.
3. Gerar o ficheiro `walkthrough.md` contendo o resumo das alterações, os trade-offs e os nomes dos commits gerados.
