# Skill: /breakdown-tasks
## Objetivo
Transformar um requisito refinado pelo Agente Product Owner em um plano de implementação com micro-tarefas sequenciais e independentes.

## Instruções de Execução
1. Analisar os critérios de aceite validados.
2. Fatiar a funcionalidade em blocos lógicos menores (Tasks).
3. Cada task deve ter escopo estrito o suficiente para gerar **um único commit atômico** pelo Desenvolvedor.
4. Gravar o resultado em `.specs/tasks.md`.
