# 🚀 Repositório Modelo SDD — Orion Stellar Solutions

## 🛠️ Stack Técnica Preferencial e Arquitetura

- **Frontend & App Engine**: TypeScript / Vue 3 (Composition API `<script setup>`), Astro ou Nuxt 3.
- **Estilização & Tipografia**: Tailwind CSS com suporte estrito à fonte Montserrat.
- **Hospedagem & Borda**: Cloudflare Pages & Cloudflare Workers (Edge Computing).
- **Garantia de Qualidade**: Vitest, ESLint, TypeScript Strict Check e Auditoria de Mutação.
- **Orçamento de Performance Mobile**: PageSpeed Insights Mobile Score $\ge 90$, LCP $\le 2.5\text{s}$, INP $\le 200\text{ms}$, CLS $\le 0.1$.
